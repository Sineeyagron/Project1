# เช็กลิสต์ทดสอบ: QR แปะคอม (ก่อน deploy)

> branch `feat-room-qr` · รายละเอียดระบบ: `docs/rules/room.md` หัวข้อ "QR แปะคอม"
> ทำทีละข้อ ผ่าน = ติ๊ก `[x]` · ไม่ผ่าน = จดสิ่งที่เห็นไว้ใต้ข้อนั้น (ถ่ายรูปจอแนบได้) แล้วส่งให้คนเขียนโค้ด

## ต้องรู้ก่อนเริ่ม
- **QR บนป้ายชี้ไปเว็บจริงเสมอ** (`labhub-kku.vercel.app`) แต่เว็บจริงยังไม่มีฟีเจอร์นี้ (ยังไม่ Sync fork)
  → ก่อน deploy: สแกนป้ายด้วย **ปุ่มสแกนในแอป** เท่านั้น (ในแอปอ่านลิงก์ได้ทุกโดเมน)
  → สแกนด้วย **กล้องมือถือธรรมดา** ทดสอบได้หลัง deploy เท่านั้น (ส่วน C)
- เตรียมบัญชี 3 แบบ: **นศ.** / **TA** / **Admin** — ถ้าล็อกอิน Google บนเครื่องทดสอบไม่ได้ ใช้อีเมล+รหัสผ่านแทน
- แจ้งปัญหาที่ส่งตอนเทสจะเข้าคิวจริง → เทสเสร็จให้ Admin กด **ปฏิเสธ** ทิ้งที่ `admin/roomreports` · นศ. 1 คนแจ้งได้ 5 ครั้ง/วัน

## เตรียมเครื่อง
- [ ] สลับ branch เป็น `feat-room-qr` ใน GitHub Desktop
- [ ] เปิด terminal ที่โฟลเดอร์ `iot-lab-management` แล้วรัน `npm run web` → เปิด `http://localhost:8081` บนคอม (ใช้ในส่วน A)
- [ ] (ส่วน B) ติดตั้งแอป **Expo Go** บนมือถือ · มือถือกับคอมต่อ Wi-Fi เดียวกัน · รัน `npx expo start` แล้วสแกน QR ใน terminal ด้วย Expo Go
- [ ] เลือกห้องทดสอบ 1 ห้อง + จด **รหัสห้อง** และชื่อเครื่องที่จะใช้เทส 2–3 เครื่อง

## A. บนเว็บในคอม (localhost)

### A1. ปุ่มใหม่ในหน้าผู้ดูแล (`admin/room`)
- [ ] ล็อกอิน Admin → หน้าระบบห้อง → การ์ดห้องมีแถวปุ่มที่ 2: **สแกน QR · ป้าย QR · สรุป PDF**
- [ ] ล็อกอิน TA → เห็นและกดปุ่มทั้ง 3 ได้เหมือนกัน

### A2. ป้าย QR
- [ ] กด **ป้าย QR** → ไอคอนหมุนระหว่างโหลด → แผ่นเลือกขนาด 3 แบบ (เล็ก / ปกติ / ใหญ่) แต่ละแบบบอกจำนวนแผ่นที่ใช้ · "ปกติ" ถูกเลือกไว้
- [ ] เลือกขนาด → ได้หน้าพิมพ์ + กล่องพิมพ์เด้งเอง · กด "ยกเลิก" ในแผ่นเลือก = ไม่ทำอะไร
- [ ] ป้ายเรียง กลุ่ม 1 → 2 → … และชื่อเครื่องเรียงเลขถูก (เช่น C2 มาก่อน C10)
- [ ] ป้ายมี: QR · "ห้อง **…**" / "กลุ่ม **…**" (2 บรรทัด เลขตัวหนา) · ชื่อเครื่องตัวใหญ่ · "สแกนดูสถานะ / แจ้งเครื่องเสีย" · LabHub (ป้ายเล็ก: "สแกนแจ้งเครื่องเสีย" ไม่มี LabHub) · ตัวหนังสือดำ ไม่ชนกัน ไม่ล้นกรอบ
- [ ] จำนวนป้ายต่อแผ่นถูก (เล็ก 32 / ปกติ 18 / ใหญ่ 8) · ป้ายไม่ถูกตัดครึ่งระหว่างหน้า
- [ ] พิมพ์จริงขนาดละ 1 แผ่น ตั้งสเกล **100% / Actual size** (ห้าม "Fit to page") → วัดด้วยไม้บรรทัด: เล็ก **4.5 × 3.2** (QR 2.2) · ปกติ **6 × 4.2** (QR 3.2) · ใหญ่ **9.2 × 6.2** (QR 5) ซม. → ลองสแกนจากระยะจริงที่จะแปะ
- [ ] เครื่องที่ถูกปิดใช้งาน **ไม่มี** ป้าย
- [ ] ห้องที่ยังไม่มีเครื่อง → ป๊อปอัป "ยังไม่มีเครื่อง" (ไม่ได้หน้าว่าง)

### A3. สรุป PDF
- [ ] กด **สรุป PDF** → ได้หน้าพิมพ์ "สรุปห้องคอม <ห้อง>" + วันเวลาตอนนี้
- [ ] ตัวเลขตรงกับหน้าแอป: เครื่องทั้งหมด / ใช้งานได้ / กำลังซ่อม / เสีย / LAN ใช้ได้ / อุปกรณ์หาย-ชำรุด / งานซ่อมค้าง / แจ้งปัญหารอตรวจ
- [ ] ตาราง "แยกตามกลุ่ม" ครบทุกกลุ่ม · ตาราง "รายการที่ต้องดูแล" มีเครื่อง/อุปกรณ์/LAN ที่มีปัญหาครบ (ห้องปกติทั้งห้อง = "ไม่มี — ทุกเครื่องปกติ")
- [ ] กดปุ่มป้าย QR/สรุป PDF รัว ๆ → ทำไฟล์แค่ครั้งเดียว

### A4. เปิดลิงก์เครื่องตอนยังไม่ล็อกอิน (จำหน้าแล้วพากลับ)
> ลิงก์ทดสอบ = ลิงก์ในป้าย แต่เปลี่ยนโดเมนเป็น localhost: สแกนป้ายด้วยแอปสแกน QR ใดก็ได้ → คัดลอกลิงก์ → แทน `https://labhub-kku.vercel.app` ด้วย `http://localhost:8081`
- [ ] ออกจากระบบ → วางลิงก์ในแถบที่อยู่ → ถูกพาไปหน้าล็อกอิน
- [ ] ล็อกอินด้วย **นศ.** → กลับมาที่ผังห้อง และ **แผ่นของเครื่องนั้นเปิดเอง** (เห็นสถานะ + ปุ่มแจ้งปัญหา)
- [ ] ทำซ้ำด้วย **Admin** → ต้องกลับมาที่เครื่องนั้นเหมือนกัน (ไม่เด้งไปหน้า admin/home) · เป็นผังโหมดนักศึกษา = ถูกต้อง
- [ ] ล็อกอินแบบปกติ (ไม่ได้เปิดลิงก์มาก่อน) → นศ. ไป home / Admin-TA ไป admin/home เหมือนเดิม
- [ ] เปิดลิงก์ตอนยังไม่ล็อกอิน แล้วรอเกิน 30 นาทีค่อยล็อกอิน → ไปหน้าปกติ (ไม่พากลับลิงก์เก่า)

### A5. สแกนในแอปผ่านกล้องคอม (ถ้ามีเว็บแคม)
- [ ] home → การ์ด **สแกน QR คอม** → ขออนุญาตกล้อง → ส่องป้าย → ไปผังห้อง + แผ่นเครื่องนั้นเปิดเอง

## B. บนมือถือ (Expo Go)

### B1. สแกนจากหน้า home (นศ.)
- [ ] การ์ด **สแกน QR คอม** อยู่เหนือ "ลิงก์ด่วน" แยกจากปุ่มสแกนยืม-คืน
- [ ] กดแล้วขออนุญาตกล้อง: ข้อความใต้ปุ่มคือ "ใช้สแกน QR ที่แปะบนเครื่องคอม"
- [ ] ส่องป้ายที่พิมพ์ → ไปผังห้อง + แผ่นเครื่องนั้นเปิดเอง · กด ← กลับ home ได้
- [ ] ปุ่มไฟฉายใช้ได้ · สแกนในที่มืด/ห่าง 30 ซม. ได้
- [ ] จากแผ่นเครื่อง กด **แจ้งปัญหา** → ส่งสำเร็จ → Admin เห็นในคิว `admin/roomreports` + ได้แจ้งเตือน
- [ ] แจ้งเรื่องเดิมซ้ำทันที → ระบบกันซ้ำ

### B2. สแกนจากหน้าผู้ดูแล (Admin / TA)
- [ ] `admin/room` → **สแกน QR** → ส่องป้าย → ผังห้อง **โหมดผู้ดูแล** (เห็นประวัติ + แก้เช็กลิสต์ได้) + แผ่นเครื่องนั้นเปิดเอง
- [ ] กด ← บนหน้าสแกน → กลับ `admin/room` (ไม่ใช่ home)

### B3. QR ผิดประเภท (ต้องไม่ปนกัน 2 ระบบ)
- [ ] หน้า **สแกน QR คอม** ส่อง **ป้ายอุปกรณ์ยืม-คืน** → ป๊อปอัป "ไม่ใช่ป้ายห้องคอม" **ครั้งเดียว** (ไม่เด้งรัว) และไม่พาไปไหน
- [ ] หน้า **สแกนยืม / คืนอุปกรณ์** ส่อง **ป้ายคอม** → สแกนไม่สำเร็จ / ไม่พบ · ต้องไม่ไปหน้าผังห้องและไม่เปิดฟอร์มยืม
- [ ] ส่อง QR อื่น (เช่น ลิงก์เว็บทั่วไป) ในหน้าสแกน QR คอม → "ไม่ใช่ป้ายห้องคอม"

### B4. เครื่องที่ไม่มีแล้ว
- [ ] Admin เพิ่มเครื่องทดสอบ (เช่น `TEST-QR`) → พิมพ์ป้ายเครื่องนี้ → **ปิดใช้งาน** เครื่องนี้ → สแกนป้าย → ป๊อปอัป "ไม่พบเครื่องนี้" แต่ผังห้องยังเปิดปกติ
- [ ] เทสเสร็จ ลบ/ปิดเครื่อง `TEST-QR` ทิ้ง

### B5. ไฟล์บนมือถือ
- [ ] `admin/room` → **ป้าย QR** และ **สรุป PDF** → ได้ไฟล์ PDF + หน้าแชร์ของมือถือ (ส่ง LINE/บันทึกไฟล์ได้) · เปิดไฟล์แล้วหน้าตาเหมือนบนเว็บ

## C. หลัง deploy (Sync fork แล้ว) — ทดสอบบนเว็บจริงทันที
- [ ] เปิด labhub-kku.vercel.app → ล็อกอินได้ · ระบบยืม-คืนยังใช้ได้ (สแกนยืม 1 ชิ้นแล้วยกเลิก)
- [ ] ออกจากระบบ → สแกนป้ายด้วย **กล้องมือถือธรรมดา** (iPhone + Android อย่างละเครื่อง) → เปิดเว็บ → ล็อกอิน **Google** → กลับมาที่เครื่องนั้น + แผ่นเปิดเอง
- [ ] ล็อกอินค้างไว้แล้วสแกนด้วยกล้องธรรมดา → ไปที่เครื่องนั้นเลยไม่ต้องล็อกอิน
- [ ] PWA ที่ติดตั้งบนหน้าจอโฮม → การ์ด สแกน QR คอม ใช้กล้องได้
- [ ] มีข้อไหนพังหนัก → ย้อนเว็บกลับ: Vercel → Deployments → อันก่อนหน้า → **Promote to Production** (ย้อนได้ทันที ไม่ต้องแก้โค้ด)
