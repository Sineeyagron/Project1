## 1. สำรองข้อมูล (แนะนำเดือนละครั้ง + ก่อนแก้อะไรใหญ่ ๆ)

Supabase แพ็กเกจฟรี **ไม่มีระบบกู้ข้อมูลย้อนหลังให้เราใช้เอง** ถ้าข้อมูลหายคือหาย ต้องสำรองเอง

1. เปิด Supabase Dashboard → **Project Settings → API**
   - คัดลอก **Project URL**
   - คัดลอก **service_role key** (กด Reveal) — ⚠️ key นี้เข้าถึงข้อมูลได้ทั้งหมด ห้ามส่งให้ใคร ห้ามใส่ในไฟล์ที่ commit
2. เปิด Terminal ที่โฟลเดอร์ `iot-lab-management` แล้วรัน (PowerShell):

   ```powershell
   $env:SUPABASE_URL="https://xxxx.supabase.co"; $env:SUPABASE_SERVICE_ROLE_KEY="วาง key ตรงนี้"; node scripts/backup-db.js
   ```

3. ได้โฟลเดอร์ `backups/<วันที่_เวลา>/` — ทุกตารางเป็น `.json` (ไว้กู้) และ `.csv` (เปิดด้วย Excel ได้) + `_summary.json` (จำนวนแถว)
4. คัดลอกโฟลเดอร์นั้นไปเก็บที่ปลอดภัย (Google Drive ส่วนตัว / ไดรฟ์ภายนอก) — โฟลเดอร์ `backups/` ไม่ขึ้น git (มีข้อมูลส่วนตัวผู้ใช้)

**สคริปต์อ่านอย่างเดียว ไม่แก้ข้อมูล** · ทุกตารางขึ้น ✓ = ครบ · มี ✗ = ตารางนั้นสำรองไม่ได้ (ข้อความบอกสาเหตุ)

**ไม่ได้สำรอง:**
- บัญชีล็อกอิน (`auth.users`) — นศ. เข้าด้วย Google อยู่แล้ว เข้าใหม่ได้เสมอ (ข้อมูลโปรไฟล์อยู่ใน `profiles.json`)
- รูปในที่เก็บไฟล์ (`item-images`, `borrow-photos`) — ถ้าต้องการ: Dashboard → Storage → เลือก bucket → ดาวน์โหลด
- `push_subscriptions` (เครื่องสมัครรับแจ้งเตือนใหม่เองได้), `client_errors` (log ชั่วคราว)

**กู้ข้อมูล:** Dashboard → Table Editor → เลือกตาราง → Insert → Import data from CSV (ทีละตาราง เรียงตามลำดับในสคริปต์ — ตารางหลักก่อน ตารางที่อ้างถึงทีหลัง) · ถ้าข้อมูลเสียหายหนัก ปรึกษาก่อนลงมือ

## 2. ดู error จากเครื่องผู้ใช้

แอปส่ง error ที่ไม่มีใครจับ (แอปพัง / ปุ่มกดแล้วเงียบ) มาเก็บที่ตาราง `client_errors` อัตโนมัติ (`lib/errorReport.ts`)
- เก็บเฉพาะผู้ที่ล็อกอินแล้ว · ข้อความซ้ำไม่เก็บซ้ำ · คนละไม่เกิน 20 รายการ/ชม. · ลบเองเมื่อเก่ากว่า 30 วัน
- อ่านได้เฉพาะ admin

ดูล่าสุด (Dashboard → SQL Editor):

```sql
select e.created_at at time zone 'Asia/Bangkok' as เวลา, p.full_name, p.email,
       e.platform, e.url, e.message, e.app_version
from client_errors e left join profiles p on p.id = e.user_id
order by e.created_at desc limit 50;
```

ข้อความเดียวกันขึ้นหลายคน = บั๊กจริง → ส่ง `message` + `stack` ให้คนแก้โค้ด

## 3. เทสกติกายืม-คืน (รันทุกครั้งที่แก้ RPC ในฐานข้อมูล)

ไฟล์ `supabase/tests/borrow_rules.test.sql` — 53 ข้อ ครอบคลุม ยืม / อนุมัติ / ปฏิเสธ / ยืมต่อ / คืน (ปกติ, ชำรุด) / หมดเวลา / โควตา / นัดรับ (กันของ, นัดเวลา) / TA ตัดสินคำขอของตัวเองไม่ได้

1. Dashboard → SQL Editor → วางทั้งไฟล์ → Run
2. ผล:
   - `ALL TESTS PASSED (53)` = ผ่านทั้งหมด (ขึ้นเป็นสีแดงแบบ error — ตั้งใจ เพื่อย้อนกลับข้อมูลทดสอบทั้งหมด)
   - `FAIL [ชื่อข้อ] ...` = ข้อนั้นพัง

**ไม่แตะข้อมูลจริง:** ผู้ใช้/อุปกรณ์/รูป/คำขอ/แจ้งเตือนที่สร้างระหว่างเทส ถูกย้อนกลับทั้งหมด (แจ้งเตือนเด้งก็ไม่ถูกส่ง)
